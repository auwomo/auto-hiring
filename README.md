# 🤖 Auwomo 人事助手

自动简历匹配 + 审批提交工具。发简历给 Bot，它会帮你分析、匹配岗位、提交审批。

---

## 怎么用？

### 第一步：发简历

直接把 **PDF 简历** 拖进飞书对话框发给 Bot 就行。

> 💡 不需要说任何话，直接发 PDF 文件就会自动触发。

### 第二步：看评估结果

Bot 会自动：
- 解析简历里的关键信息（学历、经历、技能）
- 匹配最合适的方向（具身智能 / Pretrain / 后训练部署）
- 给出评估报告（亮点 + 风险点 + 推荐等级）

### 第三步：决定要不要提交审批

看完评估后，告诉 Bot：
- 说 **"提交审批"** / **"可以"** / **"通过"** → 自动创建飞书审批
- 说 **"不合适"** / **"算了"** → 不提交，结束

### 第四步：审批自动创建

如果你确认提交，Bot 会自动：
- 把简历 PDF 上传为审批附件
- 填好所有字段（姓名、学校、经历、优劣势…）
- 以 **你的身份** 发起审批流程

之后去飞书审批里查看进度就好。

## 常见问题

**Q: 支持什么格式？**
A: 目前只支持 PDF。Word 文档请先转成 PDF 再发。

**Q: 审批发起人是谁？**
A: 是你自己。谁发的简历给 Bot，审批就以谁的名义发起。

**Q: 一面/二面的面试官怎么选？**
A: 审批流转到一面/二面节点时，由你在飞书审批里手动指定面试官。

**Q: 评估不准怎么办？**
A: 可以直接跟 Bot 说"重新评估"或者"换个方向看看"，它会调整。

**Q: 简历来源怎么填？**
A: 默认填"Auwomo 自动匹配"。如果需要改，提交前跟 Bot 说就行。

## 职责

1. 负责实验室云基础设施与服务器的部署、监控与日常运维，保障服务高可用与稳定性
2. 维护 API 网关配置层，支持团队 AI 服务的稳定接入与模型兼容性适配，配合负责人执行成本管控策略
3. 搭建并维护 DevOps 工具链，涵盖代码仓库管理、CI/CD 流水线构建与自动化部署
4. 负责实验室网络基础设施与安全体系，包括代理节点、VPN、软路由及安全系统的配置与维护
5. 承担团队 IT 支持工作，包括网站部署、合规备案、开发环境配置与日常问题排查
6. 编写运维文档与操作手册，建立标准化运维流程

## 要求

- 计算机、网络工程等相关专业本科及以上
- Linux 服务器运维经验，熟悉常见发行版的系统管理
- 熟练掌握 Docker / Docker Compose，有容器化部署与编排实际经验
- 熟悉至少一家主流云平台（AWS / 阿里云 / 腾讯云）的核心服务（计算、存储、网络、IAM）
- 有 CI/CD 实践经验（GitLab CI、GitHub Actions 或 Jenkins 均可）
- 熟悉网络基础：TCP/IP、DNS、Nginx / 反向代理、防火墙、VPN 配置
- 具备脚本编程能力（Bash / Python），能编写自动化运维脚本
- 沟通清晰，能主动发现和解决问题，适应创业团队节奏

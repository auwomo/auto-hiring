## 格式说明

每个方向包含：
- **一面面试官** — 该方向的一面负责人
- **职责** — 岗位核心职责
- **要求** — 硬性要求和软性偏好
- **优先级** — 急/正常/低
- **审批路由** — 简历推送对象

### Post-training（后训练 / RLHF）

- **一面面试官:** 马子健
- **审批路由:** 简历给马子健
- **职责:**
  1. 设计面向机器人操作的 SFT 数据管道，研究指令格式与多任务配比策略
  2. 构建 Reward Model，融合任务完成度、物理合理性与语言指令对齐信号
  3. 基于 PPO/GRPO/DPO 等算法实现 on-policy RL fine-tuning，支持仿真与真机双路径
  4. 研究 RLVR 在具身推理中的应用，提升模型对长流程任务的规划能力
  5. 建立标准化评测体系，覆盖操作精度、泛化性、安全性等维度

  - 熟悉 VLA（如 OpenVLA、π0、RoboFlamingo）或 LLM post-training 工作
  - 有仿真平台（Isaac/Mujoco）RL 训练经验，了解 sim-to-real 挑战

### Infra 加速（训练/推理基础设施）

- **一面面试官:** 郭凯文、王天亨
- **审批路由:** 简历给郭凯文
- **职责:**
  - 负责支撑 LLM 与 World Model 训练的大规模 GPU 集群基础设施，保障高可用与稳定性
  - 优化分布式训练框架（数据/模型/流水线并行），识别并解决通信、显存、IO 等性能瓶颈
  - 构建高吞吐、低延迟推理服务，覆盖量化、KV Cache 优化、Continuous Batching 等核心技术
  - 与算法团队协作，支持训练/推理快速实验迭代，评估并引入新型硬件与软件栈
- **要求:**
  - 5 年以上基础设施或系统工程经验，有大规模分布式训练/推理实际落地经验优先
  - 深入理解 GPU 体系结构，熟悉 CUDA、NCCL 及性能 profiling 工具链
  - 熟练掌握至少一种主流训练框架（Megatron-LM、DeepSpeed、PyTorch FSDP）的源码级调优
  - 熟悉推理优化方法：PagedAttention、Speculative Decoding、Continuous Batching 等
  - 具备 Kubernetes、容器化部署及 InfiniBand/RoCE 高速网络配置经验
  - 扎实的 Python / C++ 编程能力，能独立阅读并修改框架底层代码
- **加分项:**
  - 有 World Model（视频生成/物理模拟）训练或推理系统建设经验
  - 深度参与过 vLLM、TensorRT-LLM、SGLang 等开源推理框架开发
  - 在 MLSys、OSDI、SOSP、SC 等顶会发表过相关论文
- **优先级:** 急

- **审批路由:** 简历给李诗雯
- **职责:**

  2. 设计大规模自动化合成数据生产 pipeline，支持多样化场景/物体/光照随机化
  3. 研究 Domain Randomization / Real2Sim 策略，量化并缩小仿真与真机的系统差异
  4. 构建支持数千路并行的 RL 训练环境，设计 reward function 与课程学习方案

  6. 与 Pre-training / Post-training / 硬件团队协作，打通仿真数据到模型训练的完整链路
- **要求:**
  - 相关方向硕/博士，熟悉 Isaac Lab、MuJoCo 或同类平台
  - 有大规模并行仿真训练或合成数据生产实际项目经验
  - 了解机器人运动学/动力学，熟悉 URDF/MJCF 格式
  - 有 Sim-to-Real 实践经验者强烈优先
- **优先级:** 急

- **一面面试官:** 王鑫、侯志一
- **审批路由:** 简历给王鑫
- **职责:**

  2. 设计具身操作视频的自动化质量控制体系，包括异常帧检测、任务片段切分、多视角时序对齐

  6. 搭建 Agent 框架，实现仿真资产、仿真场景的自动化链路
